一、YuLink 是什么？
------------------------------------------------------------------------
YuLink 是一款专为教师、演讲者与演示工程师打造的 Office / WPS 深度增强套件。
基于 C# / VSTO 与 Microsoft Edge Chromium WebView2 内核，它能够在 PPT 全屏放映
过程中原生嵌入可交互的网页（在线网站、本地 3D 模型、课文互动点读、流媒体视频等），
彻底消除传统切出浏览器窗口的割裂感，让讲演与板书浑然一体。

------------------------------------------------------------------------
二、运行环境与系统要求 (兼容性说明)
------------------------------------------------------------------------
1. 【操作系统】：
   - Windows 10 / Windows 11 (64位) 完美原生支持。
   - 注意：Windows 7 微软已停更且缺乏现代 Chromium WebView2 内核支持，不保证可用。
2. 【Office 宿主】：
   - 硬性重点要求：Microsoft Office 2013 及以上版本（涵盖 2013 / 2016 / 2019 / 2021 / Office 365）
   - 或 金山 WPS 演示 (WPP)。
3. 【底层运行库依赖】：
   - .NET Framework 4.8 或更高版本
   - Microsoft Edge WebView2 Runtime (Chromium 网页渲染内核)
4. 【为什么您不需要手动安装依赖？】：
   - 原作者旧版需要用户手动下载安装包，而本插件全新的【一键安装.bat】与【环境检查与修复.bat】
     已经深度集成了“自动化智能诊断与静默补齐”机制：
   - 当您在任何 Win10/Win11 电脑上双击安装时，脚本会自动检测系统是否缺失上述环境；
   - 若检测到缺少 .NET 4.8 或 WebView2，脚本会自动调用微软官方通道在后台完成静默下载与安装，
     真正做到开箱即用，无需用户手动寻找安装包！

三、一键极速安装与卸载
------------------------------------------------------------------------
【快速安装】：
1. 将本文件夹解压至任意目录（建议路径不要过深）。
2. 双击运行【一键安装.bat】。
3. 脚本将自动完成环境预检、脱机编译、证书签名、信任注入与 Office 注册。
4. 打开 PowerPoint 或 WPS 演示，顶部将出现【YuLink】功能区标签！

【WPS 启用说明】：
若在 WPS 中首次未看到菜单，请按以下步骤启用：
打开 WPS -> 打开任意 PPT -> 点击左上角【文件】->【选项】->【信任中心】->
【受信任的加载项】-> 勾选【启用所有第三方 COM 加载项，重启 WPS 后生效】-> 确定并重启 WPS。

【一键卸载】：
若需从系统中完全清除插件，双击运行【一键卸载.bat】，1 秒内自动清理所有注册表项与信任缓存。

四、功能详细使用指南
------------------------------------------------------------------------
1. 【插入网页】：
   - 在 PowerPoint 顶部菜单栏点击【YuLink】->【插入网页】。
   - 幻灯片上将生成一个矩形占位符框。
   - 选中占位符框，在右侧面板或弹窗提示中输入目标网页地址（如 https://threejs.org 或 http://localhost:5173）。
   - 支持本地文件（如 file:///D:/3DModel/index.html）或 Localhost 开发服务器。

2. 【放映与缩放控制】：
   - 按 F5 开启放映，翻到该页时网页将在毫秒级完成同屏原生渲染。
   - 顶部控制栏提供：前进、后退、刷新、全屏与缩放控制。
   - Chrome 级等比缩放：点击 + / - 可在 25% 到 500% 之间精准等比缩放，悬停查看精确百分比。

3. 【拟物毛玻璃悬浮画笔】：
   - 点击顶部导航栏的【画笔】图标，右下角将呼出磨砂玻璃悬浮圆盘。
   - 支持多色笔触、粗细调节、橡皮擦与 30 步高精细撤销。
   - 一键挂起交互：点击已选颜色即可暂停涂鸦接管，无缝恢复对底层网页的点击与滚动；再次点击恢复涂鸦。
   - 智能贴边自适应：圆盘拖动到屏幕左半区向右展开，拖到右半区向左展开，永不超出屏幕边界。

4. 【本地 Localhost 手机扫码共享】：
   - 放映本地服务（如 http://localhost:3000 / Vite 开发站）时，点击导航栏【二维码】图标。
   - 插件内置轻量级透明反向代理，手机扫码后自动通过局域网拉取电脑本地的 HTML、CSS、JS 与图片等全部资产。

5. 【物理无线翻页笔直通】：
   - 即使鼠标在网页内点击夺取了 Windows 焦点，手里的无线翻页笔（PageDown/PageUp/空格/方向键）依然能丝滑换页。

6. 【Apple 现代极简移动中枢 (遥控翻页 + 实物展台)】：
   - 手机扫码后进入全新 Apple 纯白现代极简 Web 界面（扁平轻质感、触感震动反馈）：
   - ① 🎮 【智能遥控翻页】：
     - 极简扁平触控，超大 Apple 蓝【下一页】主控按钮，结合【上一页】与【视频播放/暂停】；
     - 每次触控均伴随 iOS 级触感震动（Haptic Feedback），并有状态呼吸灯实时同步。
   - ② 📷 【无线实物展台 (拍照讲评 & 实时直播)】（免安装 App，扫码即用）：
     - 📸 【一键拍照投屏】：走下讲台抓拍学生作业或试卷，1 秒内高清照片自动全屏铺满 PPT 页面，
       大屏端自动唤出 YuLink 悬浮画笔，老师可直接在投影上圈画重点、批改讲解打分！
     - 🔄 【大屏顺时针旋转】：支持 90°/180°/270° 一键旋转，横版作业与竖版试卷完美适应。
     - 🎥 【实时动态展台】：手机摄像头画面实时推流到大屏，适合实验与手作演示。
     - 💡 【补光灯】：弱光环境下一键开启手机闪光灯补光。
     - ⏹️ 【一键退出】：点击退出展台，PPT 秒级平滑恢复原幻灯片播放。
